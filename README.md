# wineui

This is a HTML/CSS/JS app that is designed to run a front end on mobile with a java and mysql backend. In this app, users can record their wine tasting and rate wines and wineries. They can get recommendations based on their likes, and they can search for new wineries and wines to try. They can even friend each other and share their favorites.

The UI should be elegant and modern, inspired by the colors of wine but with a rich and earthy color palette.
Each page will have its own CSS and JS file. Shared components (like ratings or wines) may be further split into separate code files.

# Login
First, users will login to the app if their info isn't already saved.

# Main page
On the main page, the user can search for wineries that are near their location, on a map, and by name. Below that, they can also view wines and wineries they've recently scored, as well as what their friends have scored recently.

# Winery
When the user selects a winery, that opens a new page that show information about the winery including an image, a title, description, and rating. Then there is a list of wines and their ratings.

# Wines
Each wine has a variety of attributes that are entered by the winery or by users to describe the wine, such as color, flavor profile, if it's sparkling, ABV, residual sugar, and if they classify it as dry vs sweet. The user can rate it or update their rating.
All ratings are done on a 5 star system.
